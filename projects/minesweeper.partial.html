Minesweeper AI Solver

An AI-powered solver for Minesweeper puzzles

Project Overview

This project consists of a React frontend and a Python FastAPI backend that work together to visualize an AI solving Minesweeper puzzles in real time.

AI Algorithm

  • Set operations — set pair subtraction and division to find guaranteed solutions.
  • Constraint satisfaction — forward checking and backtracking to estimate the probability of tiles being safe or bombs.
  • Bayesian analysis — when no moves are guaranteed, a Bayesian tree balances probability and information gain.
  • Heuristic optimization — for large frontiers, limits computation time and predicts based on estimated probabilities.

Key Features

  • Generate puzzles with multiple difficulty levels and board sizes.
  • Watch the AI solve boards step by step with timeline controls.
  • Control playback speed and navigate through moves.
  • Track outcomes for each puzzle (win/lose) automatically.
  • Inspect decisions via an interactive visualization of the solver’s reasoning.

Project Structure

  • Frontend: Next.js React application with interactive visualization components.
  • Backend: FastAPI Python service housing the Minesweeper solver algorithms.
  • Containerization: Docker setup for easy deployment and consistent environments.

Technical Implementation

  • Containerization: services are Dockerized for one-command, reproducible setup.
  • API flow: the frontend requests puzzle generation and receives solver moves from the FastAPI backend.
  • Real-time updates: moves stream to the UI and are rendered step-by-step for clear playback.
  • Controls: speed adjustment and move navigation are handled client-side for smooth interaction.
