Medical Bill and EOB Assistant

Full-stack health informatics project · October 2026 – Present · In progress

Overview

A team project for Georgia Tech's Introduction to Health Informatics course, developing an assistant for reviewing medical bills and explanations of benefits (EOBs). The application combines document extraction, deterministic billing checks, and an LLM-assisted review workflow to help users understand charges and identify discrepancies.

My Contributions

  • Developing document upload and extraction with pdfplumber for digital PDFs and Tesseract OCR for scanned documents and images.
  • Mapping extracted billing information into a shared structured JSON schema for downstream review.
  • Implementing Python checks for duplicate charges and arithmetic discrepancies.
  • Contributing to the shared React/TypeScript chat UI and component integration with a Django backend.

Tech Stack

React, TypeScript, Python, Django, PostgreSQL, pdfplumber, Tesseract OCR.

Current Focus

Building the document ingestion and validation workflow and integrating it with the team's application. FHIR concepts inform the shared data schema.
