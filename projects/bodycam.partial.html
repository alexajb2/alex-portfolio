AI Body Camera

Local ML system for tagging & purging police body-worn camera footage

Overview

Collaborated with the Signal Hill Police Department to build AI-driven software that identifies and categorizes police body-worn camera footage eligible for purging. The system combines transcription, text-based, and image-based ML models—run locally—to organize large backlogs of untagged videos.

Project Expo Recognition

This capstone won 1st Place, Computer Science at the UC Irvine ICS Project Expo 2025. The Expo program summarized the project as:

"Use of large language models (LLMs) and machine learning models to classify and tag video and audio footage from police data to streamline and organize police operations."

Read the UC Irvine ICS Project Expo article

Tech Stack

  • PyTorch, TensorFlow
  • faster-whisper (ASR), TorchAudio
  • OpenCV, TorchVision
  • Python, Flask, Docker

Key Features

  • Frontend: Electron + React interface for upload, classification, embedded playback, and optional manual review/purge.
  • Transcript Generator: faster-whisper with compression/volume/speech-pattern thresholds for improved ASR accuracy.
  • Transformer Model: event classification over transcript tokens (with GPT-synthesized training data).
  • ImageBind Model: multimodal joint embedding across image/audio/text/depth/thermal/IMU.
  • Feature Similarity: EfficientNet CNN trained to detect car-inspection-like visuals.
  • Ensemble: decision-tree combiner over all model outputs for the final tag.

Applications

  • Tagging and purging backlogs of untagged police videos.
  • AI suggestions for manual tagging workflows.
  • Generalizable video categorization for search/filter systems.
