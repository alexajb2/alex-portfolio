Overview

Collaborated with the Signal Hill Police Department to build AI-driven software that identifies and categorizes police body-worn camera footage eligible for purging. The system combines transcription, text-based, and image-based ML models all run locally to organize large backlogs of untagged videos.

Tech Stack

  • PyTorch, TensorFlow
  • faster-whisper (ASR), TorchAudio
  • OpenCV, TorchVision
  • Python, Flask, Docker

Key Features

  • Frontend: Electron framework with React library. Interface for police to upload videos, classify videos, view embedded and labeled videos, and optionally manually review/purge videos.
  • Transcript Generator: faster-whisper with compression/volume/speech-pattern thresholds for higher ASR accuracy.
  • Transformer Model: Event Classification based on transcripts, taking time positional text. Using GPT synthesis for a larger volumne of training data.
  • ImageBind Model: Multimodal model developed by Meta AI that learns a joint embedding space across multiple data types: Images, audio, text, depth, thermal, and IMU (motion) data.
  • Feature Similarity Model: Efficientnet is a CNN ML model trained to compare the video's visual similarity to Car Inspection Videos.
  • Ensemble Model: Decision Tree Classifier combining features from all model outputs for final classification.

Applications

  • Tagging and purging backlogs of untagged police videos.
  • AI suggestions for manual tagging workflows.
  • Generalizable video categorization for search/filter systems.
