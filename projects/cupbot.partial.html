CupBot RL

DQN + YOLO agent for the Root Pack boss in Cuphead

Overview

Trains a reinforcement learning agent to play Cuphead, targeting the Root Pack boss. A YOLO-based vision pipeline parses frames; a Deep-Q Network (DQN) learns actions from the observed state to handle a fast, visually noisy environment and reliably defeat the boss.

Tech Stack

  • Python, NumPy
  • PyTorch (DQN with replay buffer & target network)
  • OpenCV + YOLO (state extraction from frames)

Key Features

  • Deep Q-Learning: off-policy value learning with experience replay.
  • Object Detection: YOLO-driven detection for boss, projectiles, and player state.
  • Reward Shaping: custom rewards & evaluation metrics to track improvement.
  • Imitation Learning (WIP): bootstrapping via human gameplay demos.
