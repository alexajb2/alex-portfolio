Overview

This project trains a reinforcement learning (RL) agent to play Cuphead, targeting the Root Pack boss. A YOLO-based vision pipeline parses game frames; a Deep-Q Network (DQN) learns actions from the observed state. The goal is to handle a fast, visually noisy environment and reliably defeat the boss.

Tech Stack

  • Python, NumPy
  • PyTorch (DQN with replay buffer & target network)
  • OpenCV + YOLO (state extraction from frames)

Key Features

  • Deep Q-Learning: Off-policy value learning with experience replay.
  • Object Detection: YOLO-driven detection for boss, projectiles, and player state.
  • Reward Shaping: Custom rewards & evaluation metrics to track improvement.
  • Imitation Learning (WIP): Bootstrapping via human gameplay demos.
